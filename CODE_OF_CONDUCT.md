# Code of Conduct

## Our Pledge
We are committed to making participation in this project welcoming, respectful, and inclusive for everyone.

## Our Standards
Positive behavior includes respect, constructive feedback, inclusive language, empathy, and cooperation. Unacceptable behavior includes harassment, discrimination, personal attacks, trolling, and other hostile conduct.

## Enforcement Responsibilities
Project maintainers are responsible for clarifying and enforcing these standards and taking appropriate action when needed.

## Scope
This Code of Conduct applies to the repository, issues, pull requests, discussions, and other project-related interactions.

## Enforcement
Unacceptable behavior can be reported to the project maintainers. Reports will be reviewed fairly and handled confidentially when possible.

## Enforcement Guidelines
Maintainers will consider the seriousness of an incident and may issue a warning, temporarily restrict participation, or remove a contributor from the project.

This document is adapted from common open-source community Code of Conduct practices for use in this project.
