# Simple Interest Calculator

## Description
A simple calculator that calculates simple interest using the principal amount, interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Interest rate (%)
- Time period (years)

## Output
The calculator displays the calculated simple interest.

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## How to Use
1. Enter the principal amount.
2. Enter the interest rate.
3. Enter the time period.
4. Calculate the simple interest.
